# Chat Online

es un proyecto de chat en linea utilizando socket para el intercambio de mensaje en tiempo real , te registras o inicias sesion , tus datos se guardaran , tendras el apartado de perfil para ver el id de usuario que el sistema te dio , es como un numero telefonico para que otros puedan agregarte a sus lista de amigos y tu tambien puedas hacer lo mismo

## 🛠️ Tecnologías Utilizadas

- **Frontend:** 
  - HTML5
  - CSS
  - Javascript
- **Backend:** 
  - Node.js
  - MongoDB con Mongoose
  - Express
  - JSON Web Tokens (jwt)
  - bycriptjs
  - multer
  - socket.io
  - dotenv
  - cloudinary

## Como Inicializar El Proyecto 

En el Backend Debemos tener las credenciales y keys de cada servicio en el archivo `.env` como tambien el dominio donde tengas alojado tu frontend para que no haya problemas de cors . Al iguar que hacer un `npm install` para instalar todas las dependencias utilizadas Y en el frontend hacer las peteciones al dominio correcto , donde tengamos alojado nuestro backend
